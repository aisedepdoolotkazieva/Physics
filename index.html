§22. Токтун жумушу жана кубаттуулугу

Физикалык аныктамалар жана түшүнүктөр

Темадагы негизги түшүнүктөрдү жана формулаларды изилдөө үчүн карточкаларды басыңыз.

1. Токтун жумушу

+

Аныктама: Электр талаасынын чынжырча агып өткөн зарядды жылдырууда аткарган жумушу.

A = UIt

Физикалык мааниси: Электр энергиясынын башка түрдөгү энергияга (жылуулук, механикалык ж.б.) айлануусунун чени.

Эмне болгондо эмне болот: Эгер чыңалуу же ток күчү 2 эсе көбөйсө, бөлүнүп чыккан энергия да 2 эсе көбөйөт.

2. Токтун кубаттуулугу

+

Аныктама: Электр энергиясынын башка түрдөгү энергияга айлануу ылдамдыгын мүнөздөөчү чоңдук.

P = At = UI

Физикалык мааниси: Бирдик убакыт ичинде аткарылган электр тогунун жумушу.

Эмне болгондо эмне болот: Кубаттуулугу жогору болгон шайман (мисалы, чайнек) сууну тезирээк ысытат.

3. Көз ирмемдеги кубаттуулук

+

Аныктама: Өзгөрмө токтун чынжырындагы убакыттын берилген t көз ирмеминдеги кубаттуулук.

p = ui = UmIm cos(ωt) · cos(ωt + φ)

Физикалык мааниси: Белгилүү бир заматтагы чыңалуу менен ток күчүнүн көбөйтүндүсү.

Эмне болгондо эмне болот: p > 0 болгондо энергия булактан чынжырча келет; p < 0 болгондо энергиянын бир бөлүгү кайра генераторго кайтат.

4. Орточо кубаттуулук

+

Аныктама: Өзгөрмө токтун толук бир мезгил (T) ичиндеги кубаттуулуктун орточо мааниси.

P = UI cos φ

Физикалык мааниси: Чынжырда сарпталган пайдалуу активдүү кубаттуулукту билдирет.

Эмне болгондо эмне болот: Фазалык жылышуу φ = 0 болгондо кубаттуулук максималдуу болот.

5. Аракет этүүчү маанилер

+

Аныктама: Өзгөрмө токтун жылуулук аракети боюнча ага эквиваленттүү болгон туруктуу токтун мааниси.

U = Um√2,   I = Im√2

Физикалык мааниси: Вольтметр жана амперметр дал ушул аракет этүүчү маанилерди көрсөтөт.

Эмне болгондо эмне болот: Амплитудалык мааниси 311 В болгон розеткадагы өзгөрмө чыңалуунун аракет этүүчү мааниси 220 В га барабар.

6. Кубаттуулуктун коэффициенти

+

Аныктама: Өзгөрмө токтун чыңалуусу менен ток күчүнүн ортосундагы фазалык жылышуунун косинусу (cos φ).

cos φ = PUI

Физикалык мааниси: Электр тармагынын канчалык натыйжалуу колдонулуп жатканын көрсөтөт.

Эмне болгондо эмне болот: φ = ±90° (таза сыйымдуулук же индуктивдүүлүк) болгондо cos φ = 0 болуп, орточо кубаттуулук нөлгө барабар болот (P = 0).

Ачкыч ачык (Ток акпайт)

Өзгөрмө токтун чыңалуусу, тогу жана кубаттуулугунун графиктери

Параметрлерди жөндөө

Пресеттер:

Активдүү каршылыкта чыңалуу жана ток фаза боюнча дал келет (φ=0°). Бардык электр энергиясы пайдалуу жумушка (жылуулукка) айланат.
U (аракет этүүчү): 0 В
I (аракет этүүчү): 0 А
cos φ: 0
P (активдүү кубаттуулук): 0 Вт
pмакс / pмин: 0 / 0 Вт
